# EcoAware

This is the **EcoAware design**, with the same page layout, green colours,
rounded cards, homepage illustrations, navigation and page content.

The HTML and CSS have been expanded onto separate lines, and the JavaScript
has been rewritten with simple variables, functions, loops and comments.

## How to run

1. Extract the ZIP file.
2. Open the `EcoAware` folder.
3. Double-click `index.html` to open it in a web browser.
4. You do **not** need an internet connection or a web server.

## File list

- `index.html` - homepage and green hero design
- `about.html` - background and SDG 11
- `recycling-guide.html` - expandable recycling cards
- `locator.html` - fictional demonstration results
- `quiz.html` - 10-question interactive quiz
- `tips.html` - practical recycling tips
- `pledge.html` - community pledge saved in browser storage
- `contact.html` - FAQs and demo contact form
- `css/style.css` - styling and responsive rules
- `js/main.js` - mobile menu and contact form
- `js/quiz.js` - questions, scores and restart
- `js/locator.js` - postcode validation and fictional results
- `js/pledge.js` - save and remove a pledge locally

## Offline resources

- Uses built-in Arial/Helvetica fonts.
- No external pictures, CDN scripts, icon packages or APIs.
- The hero illustration is made with CSS and text/emoji symbols.
  These are displayed using the computer's built-in emoji fonts; appearance
  may vary slightly between Windows and Mac.
- All CSS and JavaScript files are saved in this project folder.

## Notes

- The postcode locator shows fictional examples, not verified recycling centres.
- The contact form validates fields but does not send or store messages.
- The pledge is saved on the same browser only using `localStorage`.
- Recycling advice varies by local council.
